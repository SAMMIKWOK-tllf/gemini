# Café 海報指令製造機

中一電腦科 × 基礎商業科:學生用 Gemini 生成 Café 推廣海報時,用呢個網頁逐步揀選項,自動砌成一句指令,再複製貼上 Gemini。

## 用法

- 直接開 `index.html`,唔需要安裝或者伺服器。
- 第 1–7 步係基商工作紙內容。
- 右上角細細嘅 🔒 掣可以開關進階指示(第 8–13 步),老師講先撳。
- 每步都可以撳提示掣,字會跳入輸入格,學生再自己改。
- 指令欄可以直接改字,撳「複製指令」就貼去 Gemini。

## 技術

單一 `index.html`,冇外部程式庫,只用 Google Fonts 嘅 Noto Sans TC。
